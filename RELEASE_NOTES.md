Spin-the-wheel random seat assignments for any teacher.

## Which file do I download?

| Computer | File |
|---|---|
| Windows (installs, adds a desktop shortcut) | **Seat.Wheel.Setup.Windows.exe** |
| Windows (no install, runs from USB) | **Seat.Wheel.Portable.Windows.exe** |
| Mac with Apple M1/M2/M3/M4 chip | **Seat.Wheel.Mac.Apple.Silicon.zip** |
| Mac with Intel processor | **Seat.Wheel.Mac.Intel.zip** |

Windows: if you see "Windows protected your PC", click **More info**, then **Run anyway**.

Mac: after dragging the app into Applications, run this once in Terminal:

```
xattr -cr "/Applications/Seat Wheel.app" && codesign --force --deep -s - "/Applications/Seat Wheel.app"
```

Full steps are in [INSTALL.md](https://github.com/lewkmiller/seat-wheel/blob/main/INSTALL.md).

## Features
- Up to 6 classes, remembered on your computer
- Absent today, Fill all seats, Start over, Full screen
- Your own title and three school colors
- 8 built-in landing sounds plus your own MP3/WAV/M4A/OGG files
- Backup files to move your setup between computers
